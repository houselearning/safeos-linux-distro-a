# Branding assets

SafeOS branding combines Windows 95/XP nostalgia with a modern Chromebook-inspired education workspace.

## Identity pillars
- Blue-gray palette with legacy gradients
- Retro typography and diagnostics overlays
- Custom startup music and boot text
- Krow Diagnostics, SafeCloud, SafeStore, and Action Bar naming throughout

## Asset sources
- `default.jpg`
- `safeos-dark.png`
- `safeos-light.png`
- `Copilot_20260321_...png` icons

- splash screen text
- desktop icon manifest
- login wall paper metadata
- kiosk and workspace themes
