# UI mockups and desktop concepts

## Desktop
- Windows 95 desktop grid with taskbar icons
- Action Bar along the bottom with pinned school apps
- Recycle Bin, File Explorer, SafeStore, and Settings pinned by default

## Dialogs
- Rounded XP-like windows
- Blue-gray gradients
- Legacy button styling with modern hover animations

## Notification center
- Glow panels, class alerts, browser warnings, and system events

## Boot and login
- Krow Diagnostics terminal overlay
- custom login wallpaper and animated logo
- assistant avatar panel for SafeAI
