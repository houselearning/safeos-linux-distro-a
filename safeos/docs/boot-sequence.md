# Boot sequence

1. Firmware loads the custom SafeOS bootloader theme.
2. Krow Diagnostics begins a fake BIOS-style scan.
3. Memory, display, USB, disk, and driver sanity checks are displayed.
4. The bootloader loads the live environment or installed system.
5. The login screen appears with retro fonts and animated status icons.
6. The Action Bar and desktop environment initialize.
7. SafeAI service, notifications, and cloud sync start in the background.
