# Themes

SafeOS ships with a retro-modern theme set that can be adapted for XFCE or KDE Plasma.

## Included concept files
- `safeos-retro-blue.theme`
- `safeos-xp-gtk.css`

## Palette
- Primary: `#1b3552`
- Secondary: `#5a7ea8`
- Accent: `#9dd7ff`
- Surface: `#d9e8f8`

## Notes
- Use the provided wallpapers and icon packs for a consistent school workstation look.
- Add optional high-contrast accessibility mode.
