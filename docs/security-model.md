# Security and safety model

## Threat model
SafeOS is built for student-owned and school-managed devices. The baseline security model includes:
- user account control and permission boundaries
- sandboxed browser and app execution
- teacher-managed restrictions
- SafeCloud lockdown policy enforcement
- AI moderation and content filters
- ZeroCheat for exam and calculator-site detection

## User protection features
- malware scanning hooks
- extension auditing
- website and app blocking
- session recording controls
- data loss prevention for school-managed accounts
