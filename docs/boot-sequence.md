# Boot sequence

1. BIOS or EFI firmware loads the GRUB entry generated by Debian live-build.
2. The selected live entry loads the Debian kernel and initramfs.
3. `live-boot` locates and mounts the read-only live filesystem.
4. `live-config` creates the live user and configures the session.
5. LightDM starts the XFCE desktop.
6. XFCE autostart launches `safeos-setup` until `/var/lib/safeos/first-run.json` exists.
7. The assistant configures a local account, locale, keyboard layout, time zone, host name, and optional larger text. It uses the installed NetworkManager editor for network access and permits offline setup.
8. The user may launch Debian Installer from the boot menu or desktop entry.

The setup record and changes are written to the current root filesystem. A live session without a configured persistence store loses them when the machine reboots. Debian Installer is present, but installation of this customized SafeOS profile is not certified.

No custom BIOS scan, Krow diagnostics, SafeAI, cloud sync, telemetry, or hidden background service is started. Device checks and diagnostic claims must come from real tools, not simulated boot text.
