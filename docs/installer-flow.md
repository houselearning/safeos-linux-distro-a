# Installer and first-run flow

## Installation stages
1. **Language and locale selection**
2. **Hardware profile detection**
3. **Krow Diagnostics preflight**
4. **Account creation**
5. **AI moderation toggle**
6. **Cloud enrollment**
7. **Desktop personalization**
8. **SafeStore and class policies sync**

## First-time setup wizard
- Create student, teacher, and admin accounts
- Select school mode: classroom, lab, kiosk, or home
- Choose wallpaper, sound scheme, and accessibility settings
- Register SafeCloud or local-only mode
